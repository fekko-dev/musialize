# License under AGPL-3.0

Musialize is licensed under AGPL-3.0 so that anyone who distributes or hosts a modified version must publish their source under the same license and keep the original copyright and attribution. GPL-3.0 was rejected because hosting a web app doesn't count as distribution under it, so a modified hosted copy could stay closed. Non-commercial licenses such as PolyForm Noncommercial were rejected because they aren't open source.

## Consequences

The copyright holder can still use the code commercially. Before accepting substantial outside contributions, add a contributor agreement (CLA) if that option should cover contributed code too.
